# Uncle Claude's Network 🚧

**Work in progress:** an Atari-style, top-down game that teaches small-business networking.

You're the new IT helper in Uncle Claude's building. You set up printers, IP addresses,
DHCP, routers and subnets, troubleshoot what breaks, and keep track of the money.
The hints get more specific the more you ask, and mistakes are part of how you learn:
if you set something up badly, you'll find out later and have to fix it.

## Play
Open `index.html` in any web browser. No install needed.

## Controls
| Key | Action |
|---|---|
| Arrows / WASD | Walk, or move in menus |
| E or Space | Use, pick up, put down, select |
| X | Back, or let go of a cable |
| H | Hint (press again for more help) |
| C | Clipboard |
| Esc | Pause menu |

The mouse works in all menus. The blinking amber arrow points at your next task.
